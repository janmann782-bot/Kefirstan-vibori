# Выборы Кефирстана 2059

Telegram-бот для ролевых парламентских выборов САР Кефирстан

## Что уже есть

- `/start` навсегда выдает человеку КАР, ТАР или МАР. ЙАР не выпадает и везде идет `N/D`
- короткая вводная про войну, Кефирский мятеж и перенос выборов
- 8 партий которые относятся к старому политическому полю до появления послекризисных партий
- ссылки на статьи партий в Aurelia Wiki
- 1 голос человека не равен 1 модельному бюллетеню. Он меняет вероятность партии в своей автономии
- население Кефирстана - `55 893 410`, из них право голоса имеют `47 760 453`
- случайная явка отдельно в каждой автономии, не 100%, считается от полного электората
- 3-дневный обычный режим и тест на 1 минуту
- карта красится по лидеру автономии и обновляется в одном сообщении
- под картой проценты всех партий по КАР, ТАР и МАР, ЙАР всегда `N/D`
- если добавить бота админом канала, он сам публикует лайв и потом редактирует это же сообщение
- парламент 240 мест: 180 списочных и 60 одномандатных
- общесоюзный барьер 4%, региональные партии имеют отдельный допуск
- скрытая админка только для Telegram ID `7787565361`
- прямые вкиды бюллетеней, подкрутка вероятности, ручная явка, смена автономии пользователю, стирание его голоса, экспорт SQLite

## Запуск

Нужен Python 3.11+

```bash
pip install -r requirements.txt
```

Создай `.env` рядом с файлами. Образец лежит в `env.example`:

```env
BOT_TOKEN=токен_от_BotFather
```

Потом:

```bash
python bot.py
```

Все лежит в 1 корневой папке. Никаких `src/`, `assets/`, `data/` и прочей археологии

## Канал

Добавь бота администратором канала. Нужны права публиковать и редактировать сообщения. После получения статуса администратора бот сам отправит текущую карту. Она станет лайв-сообщением

## Админ

`/admin` - кнопочная панель

`/adminhelp` - полный список команд

Основные команды:

```text
/open3d
/test1m
/close
/reset
/inject KAR LPK 1000
/signal TAR PNEK 10
/setturnout MAR 64
/setregion 123456789 KAR
/unvote 123456789
/setduration 30
/refresh
/stats
/export
```

`/inject` добавляет реальные модельные бюллетени прямо в текущий счет

`/signal` не добавляет бюллетени. Он меняет вероятность того что следующие модельные голоса пойдут выбранной партии

## Важное про карту

В `map_base.png` 4 исходных заливки используются как маски:

- желтая - КАР
- мятная - ТАР
- розовая - МАР
- темная - ЙАР

Если в исходнике у тебя 2 автономии на самом деле поменяны местами, ничего переделывать не надо. В `config.py` у `REGIONS` просто переставь `source_color` между нужными регионами

## Что считается каноном, а что технической моделью

Из политической системы взяты парламент на 240 мест, схема 180 списочных + 60 округов, барьер 4%, результаты 2049 и 2054 как исторический фон, автономии и партийные базы

Общее население и число имеющих право голоса теперь закреплены: `55 893 410` и `47 760 453`. Точного распределения этих избирателей между КАР, ТАР и МАР пока нет, поэтому региональный разрез в `config.py` остается техническим и суммарно дает ровно `47 760 453`. Диапазоны явки, стартовые проценты и точная формула регионального исключения тоже остаются настраиваемыми параметрами
